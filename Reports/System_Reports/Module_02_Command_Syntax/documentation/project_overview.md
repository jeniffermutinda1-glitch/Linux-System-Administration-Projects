# Project 2 — Command-Line Operations Laboratory

## 1. Project Overview

This project demonstrates fundamental Linux command-line operations, command syntax, command options, arguments and built-in documentation tools.

The practical exercises were conducted in an Ubuntu Linux environment as part of a simulated Linux System Administration training programme.

## 2. Scenario

As a junior Linux System Administrator, I was assigned to demonstrate my ability to execute basic commands, inspect directory contents, understand command options and locate command documentation.

The objective was to develop practical command-line literacy required for Linux administration and IT operations.

## 3. Project Objectives

- Execute fundamental Linux commands.
- Display system date, time and calendar information.
- Identify the current working directory.
- Inspect files and directories using `ls`.
- Understand how command options modify command behaviour.
- Access documentation using `man` and `--help`.
- Identify command types and executable locations.
- Distinguish commands, options and arguments.
- Maintain practical evidence and technical documentation.

## 4. Environment

- Operating system: Ubuntu Linux
- Virtualisation platform: Oracle VirtualBox
- Shell environment: Linux terminal
- Project category: Linux System Administration
- Training organisation: Asteria Technologies (simulation)

## 5. Practical Activities

The following activities were performed:

1. Displayed a welcome message using `echo`.
2. Retrieved local date and time using `date`.
3. Retrieved UTC date and time using `date -u`.
4. Displayed the current month using `cal`.
5. Displayed the annual calendar using `cal -y`.
6. Identified the current working directory using `pwd`.
7. Listed directory contents using `ls`.
8. Inspected directory contents using different listing options.
9. Inspected the `/etc` system configuration directory.
10. Accessed command documentation through manual pages and help options.
11. Identified command types and executable locations.
12. Analysed Linux command syntax.

## 6. Expected Competencies

Upon completing this project, the learner should be able to:

- Navigate and inspect Linux directory contents.
- Interpret basic command output.
- Apply command options appropriately.
- Identify command arguments and target locations.
- Access Linux command documentation independently.
- Explain the structure of a Linux command.

## 7. Deliverables

- Practical command execution evidence.
- Command options and arguments evidence.
- Command documentation evidence.
- Command syntax analysis evidence.
- Linux command reference sheet.
- Concepts and explanations document.
- Practical assessment report.

## 8. Project Outcome

This project establishes foundational command-line knowledge required for subsequent Linux system administration activities, including file management, permissions, process management, system monitoring and troubleshooting.
