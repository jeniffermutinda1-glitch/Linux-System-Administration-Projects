## Project Description

This project demonstrates practical knowledge of Linux command-line operations using Ubuntu.

It focuses on command syntax, options, arguments, directory inspection and accessing command documentation.

## Objectives

- Execute fundamental Linux commands.
- Inspect files and directories.
- Understand command options and arguments.
- Use manual pages and help options.
- Identify command types and executable locations.
- Maintain technical documentation and practical evidence.

## Technologies and Environment

- Ubuntu Linux
- Oracle VirtualBox
- Linux Terminal
- Bash shell

## Key Practical Commands

```bash
echo "Welcome to Linux Administration"
date
date -u
cal
cal -y
pwd
ls
ls -l
ls -la
ls -lh
ls -lah /etc
man date
date --help
man ls
ls --help
type ls
command -v ls
```

## Key Learning Outcome

Understanding the structure:

```bash
command [options] [arguments]
```

Example:

```bash
ls -lah /etc
```

This combines command execution, multiple options and a target directory.
